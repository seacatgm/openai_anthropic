# Модель ответа CTO, параметры, пробелы, сценарии

## 1. Что должен содержать ответ

Три величины на каждую компанию, каждая со статусом:

1. **Парк на конец 2025** — единственная точка, где обе компании сопоставимы: ГВт (OpenAI — раскрыто; Anthropic — оценка конкурента) и H100e (медиана + 90 % ДИ Epoch).
2. **Парк на дату слайда (nowcast)** — модель с интервалом, не точка.
3. **Сплит обучение/инференс** — только в деньгах (облачные расходы на compute), 2024–2025 факт/оценка, 2026 — сценарии. В GPU‑часах данных нет; парк взаимозаменяем (одни и те же чипы днём обслуживают пользователей, ночью — RL и эксперименты).

Формула ответа для заголовка слайда: «штуки не публикуются → считаем в ГВт и H100e; на конец 2025 OpenAI ≈ 1,9 ГВт / 1,7 млн H100e, Anthropic ≈ 1,4 ГВт / 1,2 млн H100e; в 2025 OpenAI делила compute ≈ 50/50, Anthropic ≈ 60/40 в пользу R&D; в 2026 обе смещаются к инференсу».

## 2. Формулы

Обозначения: `P_IT` — IT‑мощность парка (МВт); `η` — эффективность парка (H100e/МВт); `p_chip` — IT‑мощность на чип (Вт); `w_k` — доля чипов типа `k` по штукам; `h_k` — H100e на чип типа `k`.

- Мощность: `P_IT = (P_disclosed + ε_round) · f_def · f_acc`, где `f_def` — IT/объект (1 с вер. 0,9; иначе 1/PUE, PUE ∈ [1,1; 1,7]), `f_acc` ∈ [0,9; 1,2], `ε_round` ∈ ±50 МВт. (Epoch, S04.)
- Число чипов: `N_chips = P_IT · 10^6 / Σ_k w_k · p_k`.
- H100e: `N_H100e = N_chips · Σ_k w_k · h_k = P_IT · η`.
- Nowcast на дату `t`: `N(t) = N_2025 · g^{Δt}`, `Δt = (t − 2025‑12‑31)/365`, `g` — годовой множитель (лог‑нормальный приор), Монте‑Карло по `N_2025` (распределение Epoch) и `g`. Перекрёстная проверка «по вводам»: `N(t) = N_2025 + Σ_i ΔN_i(t)` по известным площадкам (Абилин, Rainier, Colossus 1, TPU 2026, Azure).
- Сплит в деньгах: `s_RD = C_RD / (C_RD + C_inf)`, `s_inf = 1 − s_RD`. Для 2026 — сценарии из известных агрегатов: `C_inf = C_total − C_RD` (OpenAI) или `C_total(квартал) = c · Revenue`, `C_inf = m · Revenue` при валовой марже инференса `1 − m` (Anthropic).

## 3. Рабочие примеры (наш расчёт, [E])

**OpenAI, конец 2025.** `P_IT` ≈ 1 950 МВт (медиана Epoch). Микс по штукам: Hopper 0,597 (1 453 Вт, 1,00 H100e), Blackwell 0,403 (2 090 Вт, 2,53 H100e). Средняя мощность на чип 1 709 Вт → `N_chips` ≈ 1,14 млн; H100e на чип 1,617 → 1,85 млн (Epoch с учётом распределения лага даёт медиану 1,74 млн). Вывод: **≈1,1–1,2 млн ускорителей, Hopper ≈ 60 % штук, Blackwell ≈ 63 % мощности.** Согласуется с «well over 1 million GPUs» Альтмана.

**Anthropic, конец 2025.** `P_IT` ≈ 1 380 МВт; Trainium2 — 52 % IT‑мощности → 716 МВт / 871 Вт ≈ 820 тыс. чипов ≈ 540 тыс. H100e; остальное 660 МВт NVIDIA + TPU при ~977 H100e/МВт ≈ 650 тыс. H100e и, при 1,4–1,6 кВт на чип, ≈ 420–470 тыс. чипов. Итого ≈ 1,25–1,3 млн чипов, ≈ 1,19 млн H100e. **В штуках Anthropic уже близка к OpenAI, в H100e — на ~30 % меньше**: Trainium2 = 0,66 H100e, Blackwell = 2,53.

**Anthropic, середина 2026 (штуки).** >1 млн Trainium2 (заявлено 20.04.2026) + >220 тыс. GPU Colossus 1 + TPU (до 1 млн по сделке 2025, ввод в течение 2026) + Azure/CoreWeave → 1,5–2+ млн ускорителей; в H100e — 1,19 млн + Rainier (+0,2 млн) + Colossus 1 (+0,28 млн) + часть TPU/Azure (+0,3–0,8 млн) ≈ 2,0–2,5 млн H100e к середине года при условии ввода. Это диапазон для nowcast, не факт.

**OpenAI, сентябрь 2026 (nowcast).** Приор роста: Epoch — «более чем утроится» за 2026 (в H100e); бюджет $50 млрд ≈ 3× к 2025; исторически 4× в год в H100e (2024, 2025). При `g` ∈ [2,5; 4,5], `Δt` = 0,74 (27.09.2026): 1,74 × [2,5^0,74; 4,5^0,74] ≈ 3,4–5,3 млн H100e; в ГВт при ~1 000 H100e/МВт нового Blackwell‑ввода — грубо 3,5–5,5 ГВт. Перекрёстно: один Абилин на 17.09.2026 — ~0,51 млн H100e. Черновик даёт 3–5 ГВт и 2–3 млн ускорителей — того же порядка, но без модели и интервалов.

## 5. Пробелы (что не закрыть публичными данными)

1. Ни одна компания не публикует число чипов и не публикует сплит; сплит есть только в деньгах и только через утечки (The Information, WSJ) и Epoch.
2. 1,4 ГВт Anthropic — оценка заинтересованной стороны; IT или объект — неизвестно.
3. Асимметрия учёта стороннего инференса (Epoch включает для Anthropic, исключает для OpenAI) — до 10–25 % на сравнении.
4. Винтажи прогнозов OpenAI на 2026 не совпадают ($14,1 млрд инференс — до февральского пересмотра; $32 млрд обучение — февраль; $50 млрд всего — май).
5. «Обучение» в отчётности = весь R&D‑compute; финальные прогоны — меньшая часть; доля RL/post‑training растёт и по железу похожа на инференс.
6. Данные о фактически работающих мощностях на сентябрь 2026 не публикуются; всё после конца 2025 — модель.
7. Валовая маржа инференса Anthropic в 2026 не раскрыта — сплит 2026 только сценарный.
