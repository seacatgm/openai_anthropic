Проверено 27.09.2026. Идентификаторы источников — `data/sources_2026-09-27.csv`.

## 1. Что такое H100e и откуда данные

- **H100e** — число чипов, эквивалентное по пиковым плотным 8‑битным операциям (FP8/INT8) чипу NVIDIA H100 (1 979 TFLOP/s). Для чипов без 8‑бит — 16‑бит. TPUv7 ≈ 2,3 H100e, GB200 ≈ 2,53, Trainium2 ≈ 0,66 (1 299 / 1 979) [V], S10, S04.
- **AI Chip Users explorer** (09.09.2026): оценки «используемого» compute пяти лабораторий, включая R&D, обучение и инференс; **использование ≠ владение** — OpenAI и Anthropic почти всё арендуют (Microsoft, Oracle, CoreWeave; Amazon, Google, с 2026 — SpaceX и CoreWeave) [V], S02.
- Оценки — Монте‑Карло; центральное значение — медиана; 90 % ДИ — 5‑й и 95‑й процентили. Epoch сама называет оценки для DeepMind и Meta «существенно неопределёнными» [V], S03.
- Утилизация не моделируется: «used» = операционно доступный парк [V], S04 (сноска 1).
- Данные: `https://epoch.ai/data/ai_chip_users_year_end_by_lab.csv`, `https://epoch.ai/data/ai_chip_users_intermediates_by_lab.csv`, ZIP `https://epoch.ai/data/ai_chip_users.zip`; код и ноутбуки — `https://github.com/epoch-research/ai-compute-users` (`notebooks/openai_power_model.ipynb`, `anthropic_power_2025.ipynb`, `anthropic_cloud_spend_2024.ipynb`, `openai_cloud_spend.ipynb`) [V], S03, S04. ## 4. Учёт стороннего инференса (критично для сравнения)

- Оба разработчика продают модели через API партнёров (Azure/Foundry, Bedrock, Vertex). Вопрос — считать ли это железо «их compute».
- **Anthropic** платит за это железо и учитывает всю выручку по валу, отдавая партнёрам долю (около половины валовой маржи по этим продажам; $360 млн в 2025). Epoch **включает** этот compute (≈10 % от парка Anthropic в 2025).
- **OpenAI** до апреля 2026 получала 20 % выручки от Microsoft и за железо не платила; после поправки 27.04.2026 доля от Microsoft отменена. Epoch **исключает** Microsoft‑хостинг (верхняя оценка — до ~25 % парка OpenAI).
- Следствие: сравнение 1,74 vs 1,19 млн H100e смещено против OpenAI на ~10–25 %; для слайда — одна строка оговорки. [V], S04, S21, S35.
